# DeepView — Claude Code Guidelines

## Plotting

**All figure/visualization work must follow `.claude/nature-plot.md`.**
Read that file before writing any matplotlib / seaborn / plotly code.
Key rules at a glance:
- Single-column 89 mm (3.5 in) / double-column 183 mm (7.2 in)
- Arial font, 7–9 pt
- Colorblind-safe palette (`NATURE_COLORS` defined in the file)
- Ticks inward, top/right spines off
- Save as PDF + TIFF/PNG ≥ 300 dpi
